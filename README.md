# IPC 기반 팩스 프로그램

## 프로젝트 소개

이 프로젝트는 UNIX 환경에서 제공하는 IPC(Inter-Process Communication) 기능을 실제로 활용해보기 위한 학습용 과제로 진행되었다.  
팩스(fax)의 기본 동작 원리—전송, 중계, 출력—를 세 개의 독립된 프로세스로 분리하여 구현함으로써, 프로세스 간 통신의 흐름을 명확하게 이해할 수 있도록 설계하였다.

특히 다음과 같은 점을 목표로 했다:

- 프로세스 간 데이터를 안전하게 전달하는 구조 익히기  
- System V 메시지 큐를 활용한 비동기 통신 방식 경험  
- 클라이언트–서버–프린터로 이어지는 작업 파이프라인 구성  
- 실제 팩스 전송 흐름을 단순화하여 소프트웨어적으로 재현  

이 프로젝트는 단순 기능 구현이 아니라, 프로세스 분리와 메시지 큐 기반 통신 구조를 직접 다루면서 시스템 프로그래밍의 핵심 개념을 실습하는 데 중점을 두었다.

---

## 주요 기능

- **클라이언트–서버 구조**
  - `client`: 팩스 데이터 전송
  - `server`: 클라이언트 메시지 수신 및 전달
  - `printer`: 최종 출력 처리

- **IPC 메커니즘**
  - System V 메시지 큐 사용
  - `msgtype.h`에서 메시지 타입 정의
  - `data.h`에서 공유 데이터 구조 정의

- **팩스 시뮬레이션**
  - `snowman.txt`, `nosurprises.txt`, `allIWantFor.txt` 등 다양한 예제 텍스트 제공
  - 클라이언트가 텍스트 파일을 팩스 페이지처럼 전송 가능

## 파일 구조

- **Makefile** :  빌드 스크립트
- **client.c** :  클라이언트 프로그램
- **server.c** :   서버 프로그램
- **printer.c** :  프린터 프로세스
- **data.h** :  공유 데이터 구조 정의
- **msgtype.h** :  메시지 타입 및 큐 설정
- **ganaKeyFile** :  IPC 키 생성용 파일
- ***.txt** :  테스트용 텍스트 파일들

## 빌드 방법

```sh
make
```

생성되는 파일
- server
- client
- printer

## 사용 방법
1. 서버 실행
  ```sh
	./server
  ```
2. 프린터 실행
  ```sh
	./printer
  ```
3. 클라이언트로 팩스 전송
  ```sh
	./client <파일명>
  ```

### 프로그램 흐름
client → message queue → server → message queue → printer
